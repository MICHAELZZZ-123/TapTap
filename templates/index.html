Shortcuts

Use these fixed shortcuts anywhere in TapTap unless noted.

TapTap

Ctrl+N
Start a new event
Ctrl+S
Add or save the current event
Ctrl+R
Refresh event data without reloading TapTap
Alt+P
Open or close Past Events when not typing
Ctrl+Z
Restore the latest available deletion outside text fields
Shift+/
Open or close this list
Esc
Close an open panel or cancel the current form

Choice menus

Enter Space ↑ ↓
Open and navigate choices
Home End
Move to the first or last choice
Enter Space
Select a choice
Esc Tab
Close the choice menu

Enter behaves normally in form fields. Use the save shortcut or button when the event is ready.
